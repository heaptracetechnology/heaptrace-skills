# heaptrace-cloud-engineer

Cloud engineering skills for Claude Code — AWS infrastructure, Terraform, security, and operations.

## Skills

| Skill | Description |
|-------|-------------|
| `vpc-design` | Design AWS VPC networks and subnets |
| `ecs-deploy` | Deploy containerized apps to AWS ECS |
| `rds-setup` | Set up and configure AWS RDS databases |
| `iam-policy` | Write least-privilege IAM policies |
| `terraform-module` | Create reusable Terraform modules |
| `ci-cd-pipeline` | Build CI/CD pipelines for cloud deployments |
| `monitoring-setup` | Set up CloudWatch monitoring and alerting |
| `cost-optimize` | Identify and reduce cloud infrastructure costs |
| `disaster-recovery` | Plan and implement disaster recovery strategies |
| `secrets-manage` | Manage secrets with AWS Secrets Manager and Vault |
| `cloud-plan` | Plan multi-cloud architectures and migrations |
| `credential-lifecycle` | Manage credential rotation and lifecycle |
| `identity-hardening` | Harden identity and access management |
| `network-security` | Design network security controls and segmentation |

## Usage

Type `/vpc-design`, `/ecs-deploy`, `/iam-policy`, etc. in Claude Code to invoke any skill.
