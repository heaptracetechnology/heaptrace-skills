# heaptrace-designer

UI/UX design skills for Claude Code — wireframes, flows, design systems, and accessibility.

## Skills

| Skill | Description |
|-------|-------------|
| `wireframe` | Create wireframes and low-fidelity mockups |
| `user-flow` | Map user journeys and interaction flows |
| `design-system` | Design and document component design systems |
| `ux-audit` | Audit UX for usability and experience issues |
| `responsive-design` | Design responsive layouts for all screen sizes |
| `micro-interaction` | Design micro-interactions and motion patterns |
| `a11y-design` | Design for accessibility (WCAG compliance) |
| `design-handoff` | Prepare design handoff specs for developers |

## Usage

Type `/wireframe`, `/user-flow`, `/ux-audit`, etc. in Claude Code to invoke any skill.
