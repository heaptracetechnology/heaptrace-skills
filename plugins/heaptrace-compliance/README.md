# heaptrace-compliance

Compliance and security skills for Claude Code — HIPAA, GDPR, SOC2, PCI-DSS, and hardening.

## Skills

| Skill | Description |
|-------|-------------|
| `hipaa-audit` | Audit systems for HIPAA compliance gaps |
| `gdpr-audit` | Audit for GDPR data protection compliance |
| `soc2-audit` | Prepare for SOC2 Type I/II audits |
| `pci-audit` | Audit payment systems for PCI-DSS compliance |
| `access-audit` | Review access controls and permissions |
| `audit-log` | Design and implement audit logging systems |
| `cloud-security` | Audit cloud infrastructure security posture |
| `dep-vuln` | Scan and remediate dependency vulnerabilities |
| `incident-plan` | Create security incident response plans |
| `infra-harden` | Harden infrastructure against attacks |
| `network-audit` | Audit network security configurations |
| `privacy-review` | Review data handling for privacy compliance |
| `secrets-scan` | Scan codebases for exposed secrets |
| `compliance-report` | Generate compliance reports for stakeholders |

## Usage

Type `/hipaa-audit`, `/gdpr-audit`, `/secrets-scan`, etc. in Claude Code to invoke any skill.
