# heaptrace-qa

QA skills for Claude Code — test planning, E2E, API testing, accessibility, and load testing.

## Skills

| Skill | Description |
|-------|-------------|
| `test-plan` | Create comprehensive test plans |
| `e2e-test` | Write end-to-end tests for critical flows |
| `api-test` | Test APIs with structured request/response validation |
| `regression-check` | Run and document regression test cycles |
| `bug-report` | Write detailed, reproducible bug reports |
| `load-test` | Design and run load and stress tests |
| `accessibility-audit` | Audit apps for accessibility compliance |
| `test-data-gen` | Generate realistic test data sets |

## Usage

Type `/test-plan`, `/e2e-test`, `/api-test`, etc. in Claude Code to invoke any skill.
