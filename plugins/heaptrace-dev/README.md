# heaptrace-dev

Core developer skills for Claude Code — covering the full daily development workflow.

## Skills

| Skill | Description |
|-------|-------------|
| `feature-plan` | Plan a new feature from requirement to implementation-ready breakdown |
| `feature-work` | Execute feature implementation with structured steps |
| `find-fix` | Diagnose and fix bugs systematically |
| `code-review` | Review code for logic errors, security, and best practices |
| `test-gen` | Generate unit and integration tests for existing code |
| `smart-commit` | Write clear, conventional commit messages |
| `explain` | Explain code, concepts, or decisions in plain language |
| `sec-audit` | Audit code for security vulnerabilities |
| `release-notes` | Generate structured release notes from changes |
| `suggest` | Suggest improvements and refactors for existing code |
| `quick-plan` | Rapid planning for small tasks and fixes |
| `quick-work` | Fast execution mode for well-defined tasks |
| `code-standards` | Enforce and document team coding standards |

## Usage

Type `/feature-plan`, `/code-review`, `/find-fix`, etc. in Claude Code to invoke any skill.
