# heaptrace-business

Business and product skills for Claude Code — PRDs, stories, proposals, and stakeholder communication.

## Skills

| Skill | Description |
|-------|-------------|
| `prd-write` | Write product requirements documents |
| `user-story` | Create well-formed user stories with acceptance criteria |
| `client-proposal` | Draft client proposals and project scopes |
| `competitor-analysis` | Analyse competitors and market positioning |
| `feature-prioritize` | Prioritize features using structured frameworks |
| `metrics-define` | Define success metrics and KPIs |
| `scope-negotiate` | Negotiate scope changes with stakeholders |
| `stakeholder-update` | Write stakeholder progress updates and reports |

## Usage

Type `/prd-write`, `/user-story`, `/client-proposal`, etc. in Claude Code to invoke any skill.
