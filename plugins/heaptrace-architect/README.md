# heaptrace-architect

Technical architecture skills for Claude Code — system design, APIs, databases, events, and migrations.

## Skills

| Skill | Description |
|-------|-------------|
| `system-design` | Design scalable system architecture from requirements |
| `api-design` | Design RESTful and GraphQL APIs with contracts |
| `db-design` | Design relational and NoSQL database schemas |
| `event-design` | Design event-driven systems and message queues |
| `integration-plan` | Plan third-party and internal service integrations |
| `migration-plan` | Plan data and schema migrations safely |
| `scalability-review` | Audit architecture for scalability bottlenecks |
| `cost-estimate` | Estimate infrastructure and development costs |

## Usage

Type `/system-design`, `/api-design`, `/db-design`, etc. in Claude Code to invoke any skill.
