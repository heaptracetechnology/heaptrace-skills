# heaptrace-automation-qa

Automation QA skills for Claude Code — Cypress, CI pipelines, contracts, and visual regression.

## Skills

| Skill | Description |
|-------|-------------|
| `cypress-test` | Write Cypress E2E tests for web applications |
| `ci-test-pipeline` | Set up automated test pipelines in CI/CD |
| `contract-test` | Design and implement API contract tests |
| `mock-service` | Create mock services for isolated testing |
| `visual-regression` | Set up visual regression testing workflows |
| `test-coverage` | Analyze and improve test coverage |

## Usage

Type `/cypress-test`, `/ci-test-pipeline`, `/contract-test`, etc. in Claude Code to invoke any skill.
