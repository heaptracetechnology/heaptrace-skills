# heaptrace-lead-engineer

Lead engineer skills for Claude Code — sprint planning, architecture, team leadership, and incidents.

## Skills

| Skill | Description |
|-------|-------------|
| `sprint-plan` | Plan sprints with capacity and priority alignment |
| `arch-review` | Review architecture decisions and trade-offs |
| `tech-debt-audit` | Identify and prioritize technical debt |
| `incident-response` | Lead incident response and post-mortems |
| `pr-strategy` | Define PR review strategies and workflows |
| `onboard-dev` | Create onboarding plans for new developers |
| `perf-audit` | Audit application performance bottlenecks |
| `decision-doc` | Write architecture decision records (ADRs) |
| `message-craft` | Craft clear technical messages and updates |

## Usage

Type `/sprint-plan`, `/arch-review`, `/tech-debt-audit`, etc. in Claude Code to invoke any skill.
